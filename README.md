# PQC-based Authentication for Internet of Drones (IoD)

This repository contains a simple simulation of post-quantum authentication for UAV networks.

## Files

auth_simulation.py  
Simulates initial authentication between drone and ground control station.

reauth_simulation.py  
Implements lightweight re-authentication using hash tokens.

performance_graph.py  
Compares authentication time between full authentication and lightweight re-authentication.

## Purpose

Reduce repeated authentication overhead in UAV networks using lightweight re-authentication.
